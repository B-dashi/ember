# Ember – Version 1.0

Dies ist das komplette GitHub-Pages/PWA-Projekt fuer Ember.

## Dateien

- index.html – Hauptseite der App
- styles.css – komplettes Design
- app.js – Logik, Tracking, Einstellungen und lokale Speicherung
- manifest.webmanifest – PWA-Konfiguration
- service-worker.js – Offline-Cache und Update-Handling
- app-icon-iphone-180x180.png – iPhone Home-Bildschirm-Icon
- app-icon-pwa-192x192.png – kleines PWA-Icon
- app-icon-pwa-512x512.png – grosses PWA-Icon
- app-icon-maskable-512x512.png – maskierbares PWA-Icon fuer verschiedene Geraete
- browser-favicon-32x32.png – kleines Browser-Tab-Icon

## GitHub

Alle Dateien direkt in das Hauptverzeichnis des Repositorys `ember` hochladen. Kein zusaetzlicher Unterordner.
